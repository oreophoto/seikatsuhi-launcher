# seikatsuhi-launcher

生活費精算アプリ（Google Apps Script のウェブアプリ）の入り口ページ。
GAS のウェブアプリには iPhone のホーム画面用のアイコン（apple-touch-icon）を付けられないので、
このページにアイコンを付け、開いたらアプリへ移動する。

- ホーム画面に追加するときは、URL の末尾に `#add` を付けて開く（移動せずに手順を表示する）。
- アプリのデータは、許可したGoogleアカウントでしか読み書きできない。このページにはデータは含まれない。
- 元のファイルは非公開リポジトリの `launcher/` にあり、このリポジトリにはそこから送っている。直接編集しない。
